# confia360-motor

Motor común de ConfIA360. El radar lo usa ya. La clínica puede usar el expediente y el mando con sus propias etapas. No debe usar las etapas ni los módulos del radar.

Incluye el expediente (estado, nota, alarma, cita e historial), los nombres de las etapas del comercial, el mando y la cuenta de módulos del radar.

No incluye gabinete, pacientes, ofertas, guiones ni envío de mensajes.
